# Kakeibo

Pythonで開発したCLI型の家計簿アプリです。

日々の支出を記録し、購入履歴の確認や商品検索、予算との比較、当日の支出統計などを行うことができます。

## 主な機能

- 支出データの追加・削除・変更
- 購入履歴の表示
- 商品名による検索
- 日付の保存
- 今日の支出統計（購入件数・支出合計）
- 予算の設定
- 予算との比較
- 支出データの保存
